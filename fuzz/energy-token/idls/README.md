# IDL Files

Place your program's IDL JSON file here as `energy-token.json`.

## Generating IDL

If you have the legacy (v0.29) IDL format:
```bash
anchor idl convert target/idl/energy-token.json -o fuzz/energy-token/idls/energy-token.json
```

If you have the new IDL format (v0.30+), copy it directly.
